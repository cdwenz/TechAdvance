# TechAdvance - Reconstrucción del Sitio Web

## 1. Project Description
Reconstrucción de la página de inicio de TechAdvance (https://techadvancement.com/), una plataforma de tecnología distribuida para empoderar la traducción de la Biblia. El sitio proporciona recursos, herramientas, kits de traducción, capacitación y soporte para traductores locales.

**Público objetivo:** Traductores de la Biblia, equipos de traducción, líderes religiosos y organizaciones misioneras.

**Valor principal:** Facilitar el acceso a tecnología y herramientas gratuitas para la traducción de la Biblia en todos los idiomas.

## 2. Page Structure
- `/` - Home (Página de inicio con hero, recursos, herramientas, documentos, contacto y footer)

## 3. Core Features
- [ ] Hero con fondo parallax y branding TechAdvance
- [ ] Navegación principal con menú desplegable (Resources, POD Reference, Helpdesk)
- [ ] Sección de botones rápidos (Helpdesk, Training, Translation, Tools)
- [ ] Sección de Recursos con tarjetas de herramientas (Translation Tools, Translation Kits, Translation Methods, Publication Process, Distribution)
- [ ] Barra de búsqueda
- [ ] Sección de Documentos con banner
- [ ] Sección de herramientas de traducción con call-to-action
- [ ] Sección de contacto (Telegram, Discord, Helpdesk Email)
- [ ] Footer completo con formulario de contacto, links y copyright

## 4. Data Model Design
No se requiere base de datos. El sitio es estático informativo.

## 5. Backend / Third-party Integration Plan
- No se requiere Supabase, Shopify ni Stripe para esta fase.
- El sitio es una página de inicio informativa estática.
